Git Workflow Cycle:


1. Edit: Modify or create files in the local repository.
   Example: echo "content" > file.txt

2. Add (Stage): Stage the changes for the next commit.
   Example: git add file.txt

3. Commit: Record the staged changes into the local repository history.
   Example: git commit -m "Add file.txt"

4. Push: Upload local branch commits to the remote repository.
   Example: git push origin main
